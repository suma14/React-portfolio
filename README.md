### 🌐 Personal Portfolio Website (React)

A modern, responsive personal portfolio built using React.js to showcase my projects, skills, academic background, and professional experience. The website features smooth navigation for an enhanced user experience.

### 🚀 Live Demo

🔗 Website: https://suma14.github.io/React-portfolio/

### 📌 Features

⚛️ Built with React.js and modern JavaScript (ES6+)

📱 Fully responsive design for all devices

🧭 Sticky navigation bar visible while scrolling

🔄 Scroll-based & click-based navigation

🧩 Modular & reusable components

🎨 Styled using CSS Modules

🚀 Deployed using GitHub Pages

⚡ Fast build with Vite

### 🛠️ Tech Stack

Frontend: React.js, JavaScript, HTML5, CSS3

Styling: CSS Modules

Build Tool: Vite

Version Control: Git, GitHub

Deployment: GitHub Pages
